Project Overview

The Random Password Generator is a Python-based web application that generates random passwords according to the length specified by the user. It uses Python's secure random generation module to create passwords containing letters, numbers, and special characters.

Features

- Generates random passwords.
- Custom password length (8–64 characters).
- Uppercase and lowercase letters.
- Numbers and special characters.
- Simple, responsive web interface.
- Input validation.
- Built with Python and Flask.

Technologies Used

- Python
- Flask
- HTML
- CSS

How to Run

1. Install Python.
2. Install dependencies:
   "pip install -r requirements.txt"
3. Run the application:
   "python app.py"
4. Open your browser and visit:
   "http://127.0.0.1:5000"
